# python-practice

Cloudflare Pages로 배포하는 가장 기본적인 정적 웹 앱입니다.

## 구성

- `index.html`: 브라우저가 처음 읽는 페이지입니다. `Hello World!` 제목과 소개 문구를 표시합니다.
- HTML 주석(`<!-- ... -->`)은 각 코드가 하는 일을 설명하며, 웹페이지 화면에는 표시되지 않습니다.

## 실행과 배포

`index.html`을 브라우저로 열어 화면을 확인할 수 있습니다. 이 저장소의 `main` 브랜치에 변경 사항을 푸시하면 Cloudflare Pages가 자동으로 배포합니다.
